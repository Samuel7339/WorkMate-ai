# WorkMate AI Runbook

## 1. Overview

WorkMate AI is an AI-powered employee helpdesk assistant for:

- HR requests
- IT support
- Facilities requests
- Company policy questions

The backend uses FastAPI, LangChain, LangGraph, SQLite, and Gemini.

The frontend uses React and Vite.

---

## 2. Requirements

Install:

- Python 3.13
- Node.js
- npm
- Git

A Google Gemini API key is required for AI model calls.
